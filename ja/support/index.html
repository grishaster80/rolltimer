よくある質問

スマートフォンをロックすると合図が聞こえない

メディアの音量を上げてください（合図はメディアとして再生されるため、iPhoneでは消音モードがオンでも鳴ります）。合図ごとの音量はタイマーのサウンドで設定でき、マスター音量はその画面の一番上にあります。

ロック画面にタイマーが表示されない

システムの設定でRoll Timerの通知を許可してください。iPhoneでは設定 → Roll Timer → ライブアクティビティも確認してください。これらがオフでもタイマーは動き続けますが、ロック画面には表示されません。

Android：画面がオフになるとタイマーが止まる

一部のスマートフォンは、バックグラウンドのアプリを積極的に終了させます。設定 → アプリ → Roll Timer → バッテリーを開き、制限なしを選んでください。Roll Timerがバックグラウンドで動作するのは、トレーニングの実行中だけです。

1つのラウンドだけを変更するには？

タイマーの設定を開き、カスタムに切り替えます。変更したいラウンドやレストをタップしてください。塗りつぶされたブロックが変更済みのものです。

画面を消灯させないようにするには？

ホーム → 設定（スライダーのアイコン）→ 画面を消灯しない、画面を明るくする、明るさ。

削除したタイマーは元に戻せますか？

数秒以内に元に戻すをタップしてください。それを過ぎると完全に削除されます。プリセットのタイマーが再び表示されるのは、すべてのタイマーを削除したときだけです。

ウォッチでRoll Timerを使うには？

Apple Watch：ウォッチアプリはiPhoneアプリと一緒に提供されます。ウォッチにない場合は、iPhoneのWatchアプリを開き、利用可能なAppの一覧からRoll Timerをインストールしてください。Wear OS：ウォッチでGoogle PlayからRoll Timerをインストールしてください。スマートフォンにGoogle PlayからインストールしたRoll Timerと連携して動作します。タイマーはウォッチでもスマートフォンでも開始できます。合図はスマートフォンが鳴らし、ウォッチにはタイマーが表示され、一時停止・スキップ・終了ができます。

Questions fréquentes

Je n’entends pas les signaux quand le téléphone est verrouillé

Montez le volume multimédia (les signaux sont lus comme des médias : sur iPhone, ils sonnent donc aussi en mode silencieux). Chaque signal a son propre volume dans l’écran Sons du minuteur ; le volume général se trouve en haut de cet écran.

Le minuteur n’apparaît pas sur l’écran verrouillé

Autorisez les notifications pour Roll Timer dans les réglages du système. Sur iPhone, vérifiez aussi Réglages → Roll Timer → Activités en direct. Le minuteur continue de tourner sans elles ; vous ne le verrez simplement pas sur l’écran verrouillé.

Android : le minuteur s’arrête quand l’écran est éteint

Certains téléphones ferment les applications en arrière-plan de façon agressive. Ouvrez Paramètres → Applications → Roll Timer → Batterie et choisissez Non restreinte. Roll Timer ne s’exécute en arrière-plan que pendant une séance.

Comment modifier un seul round ?

Ouvrez les réglages du minuteur et passez en mode Personnalisé. Touchez un round ou un repos pour le modifier ; les blocs pleins sont ceux que vous avez modifiés.

Comment garder l’écran allumé ?

Accueil → réglages (icône à curseurs) → Garder l’écran allumé, Écran lumineux et Luminosité.

Puis-je récupérer un minuteur supprimé ?

Touchez Annuler dans les secondes qui suivent. Passé ce délai, il est définitivement supprimé ; les minuteurs prêts à l’emploi ne reviennent que lorsque tous les minuteurs ont été supprimés.

Comment utiliser Roll Timer sur ma montre ?

Apple Watch : l’app pour la montre est fournie avec l’app iPhone ; si elle n’est pas sur votre montre, ouvrez l’app Watch sur l’iPhone et installez Roll Timer depuis la liste des apps disponibles. Wear OS : installez Roll Timer depuis Google Play sur la montre ; elle fonctionne avec Roll Timer installé depuis Google Play sur votre téléphone. Lancez un minuteur sur la montre ou sur le téléphone : le téléphone joue les signaux, la montre affiche le minuteur et permet de le mettre en pause, de passer ou d’arrêter.
